# Релизы

Здесь лежат готовые сборки **текущей** версии. История версий и старые сборки — на странице Releases:
https://github.com/Re-username/ScanPort/releases

- `PortScanner-web-v*.zip` — статический веб-сайт. Сам по себе не сканирует: нужен хост, который отвечает на `api/scan/*` (например, сервер из `src/PortScanner.Server`).
- `ScanPort-app-windows-x64-v*.exe` — **приложение** для Windows (Windows 10 1809+): **один файл**. SFX-лаунчер (как у FileChat): при первом запуске распаковывается в `%LOCALAPPDATA%\ScanPort\App` и открывает нативное окно. Требуется WebView2 (есть в современной Windows 10/11).
- `ScanPort-android-v*.apk` — приложение для Android (Android 7.0+). Установить APK, разрешив установку из неизвестных источников.
- `ScanPort-server-windows-x64-v*.zip` — сервер одним файлом: поднимает API на всех сетевых интерфейсах и открывает интерфейс в браузере (сканирование с других устройств в LAN). При первом запуске Windows спросит про брандмауэр — разрешите. Флаги: `--no-browser`, `--urls http://127.0.0.1:5080` (только этот компьютер).

> **Про предупреждение SmartScreen.** `ScanPort.exe` не имеет цифровой подписи (она платная), поэтому Windows может показать синее окно «Предотвратил запуск неопознанного приложения». Это не вирус — нажмите «Подробнее» → «Выполнить в любом случае». Предупреждение перестанет появляться, когда у файла появится репутация у Microsoft.

Пересборка: `powershell -ExecutionPolicy Bypass -File ../tools/build-release.ps1` (из корня репозитория).
