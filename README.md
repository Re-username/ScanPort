# Сканер открытых портов

Веб-приложение (Blazor WebAssembly) для проверки открытых TCP/UDP-портов на устройстве в локальной сети: TCP-сканирование соединений, UDP-пробы, захват баннеров служб, ICMP-ping, сортировка результатов, журнал событий, тёмная/светлая тема.

Клиент обращается к HTTP API `api/scan/*` — его должен предоставлять хост, на котором размещён сайт.

## Структура

- `Исходники/` — проект Blazor WebAssembly (`dotnet build` / `dotnet publish`)
- `Инструменты/` — иконки и тестовые скрипты (`tcp-banner-test.ps1`, `udp-echo-test.ps1` — локальные заглушки служб для проверки захвата баннеров)

## Сборка

```bash
dotnet publish Исходники/PortScanner.csproj -c Release -o Приложение
```
